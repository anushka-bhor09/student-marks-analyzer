# Student Marks Analyzer 📊

A beginner-friendly Python project that helps manage student marks and analyze class performance. It calculates total marks, percentages, and grades for students and displays a summary of the class.

## ✨ Features

- Add student names and marks.
- Validate marks between 0 and 100.
- Prevent duplicate student names.
- Display marks for Maths, Science, and English.
- Calculate total marks, percentage, and grade.
- Show the class average.
- Identify the class topper and the lowest-scoring student.
- Handle invalid inputs with simple error messages.

## 🛠️ Technologies Used

- **Python**
- Lists and dictionaries
- Functions and loops
- Conditional statements
- Exception handling

## 🚀 How to Run

**Step 1:** Make sure Python is installed on your computer.

**Step 2:** Download or clone this repository.

**Step 3:** Open a terminal in the project folder.

**Step 4:** Run the following command:

```bash
python marks_analyzer.py
```

If your system uses `python3`, run:

```bash
python3 marks_analyzer.py
```

## 📋 How It Works

1. Choose **Add student** from the menu.
2. Enter the student's name and marks in three subjects.
3. Choose **View all results** to see totals, percentages, and grades.
4. Choose **View class summary** to see the class average, topper, and lowest-scoring student.
5. Choose **Exit** to close the program.
